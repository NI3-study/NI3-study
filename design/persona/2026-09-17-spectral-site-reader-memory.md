# 기억 파일 — 스펙트럼 다리 렌더 페이지 독자

독자 조건·목적: 학부 2~3학년. MLP·softmax·역전파·그래프·인접 행렬·BFS·행렬 곱은 안다. $Av=\lambda v$는 "본 적 있다" 수준. 라플라시안·푸리에·필터·스펙트럼·Chebyshev는 모른다. 목적은 GCN의 $\hat A$가 어디서 왔는지 알고 02 논문 해설을 읽을 준비를 하는 것.

## 현재 지식과 이해

### 03에서 얻은 것
- $Z=XW$는 정점마다 같은 MLP. 여기엔 $A$가 없어서 이웃을 모른다. [03 §1]
- 왼쪽에 $A$를 붙이면 $AX$가 이웃 합, 오른쪽 $W$가 특성 변환. 왼쪽=정점 축, 오른쪽=특성 축. [03 §2.1, §8]
- $\tilde A=A+I$는 자기 자신을 넣는 것. $\tilde D$는 자기 연결을 **넣은 뒤** 다시 센 차수. [03 §2.2–2.3]
- $\hat A=\tilde D^{-1/2}\tilde A\tilde D^{-1/2}$, 성분은 $\tilde A_{ij}/\sqrt{\tilde d_i\tilde d_j}$. G4(문서 표현으로는 "정전 그래프", $E=\{(1,2),(1,3),(2,4)\}$)에서 $\tilde d=(3,3,2,2)$, $\hat A_{11}=1/3$, $\hat A_{13}=1/\sqrt6$, $\hat A_{33}=1/2$. [03 §2.3]
- 대칭 정규화를 고른 이유 둘: 보내는 쪽 차수가 계수에 남는다, 고유벡터를 서로 수직으로 잡을 수 있다. 행 평균 $\tilde D^{-1}\tilde A$는 행 합 1을 얻는 대신 비대칭. [03 §2.3]
- GCN 한 층 $H^{(l+1)}=\sigma(\hat AH^{(l)}W^{(l)})$. $\sigma$가 없으면 두 층이 $\hat A^2XW$로 접힌다. [03 §3]
- $W$는 층당 하나이고 정점 수와 무관. 순열 $P$에 대해 $\hat A'X'W=P\hat AXW$. [03 §4–5]
- 깊이 $k$ = 최대 $k$-hop. 그러나 **도달과 기여는 다른 양**이다. $k=3$에서 v3 기준 기여는 0.347 / 0.329 / 0.159 / 0.056. G4▲(잎 넷을 더한 확장)에서 수용 집합이 1→2→5→8로 늘고, 왼쪽↔오른쪽 통로는 계수 $\hat A_{12}=0.20$ 하나. [03 §6 + depth-frames 그림]
- oversmoothing / oversquashing은 **후대 용어**이고 원 논문 것이 아니다. [03 §6]

### 05에서 얻은 것 (걸음 순서대로)
- S1 간선 양 끝 값의 차: $-1,-2,-2$. S2 제곱해서 더하면 **거칢** $E(x)=9$. 거칢은 신호 크기의 **제곱**에 비례($x\to2x$면 $9\to36$).
- S3 $\Delta=D-A$(그래프 라플라시안, 비정규화). $x^\top\Delta x=9$로 S2와 같은 수. $\Delta$의 한 행 = "자기 값 − 이웃 평균"에 차수를 곱한 것. 논문 식 (1)의 좌변은 순서쌍 이중합이라 18, 이 사이트는 9를 쓴다.
- S4 $L=D^{-1/2}\Delta D^{-1/2}=I-S$, $S=D^{-1/2}AD^{-1/2}$. **여기 차수는 $d=(2,2,1,1)$**(자기 연결 없는 쪽). $S_{12}=0.5$, $S_{13}=S_{24}=0.7071$. $Lx=(-2.1213,-1.3284,2.2929,2.5858)$, $x^\top Lx=12.4437$.
- S5 $Lu=\lambda u$를 만족하는 네 방향(고유벡터) + 배수(고유값). 길이 1판: $u_1=(0.5774,0.5774,0.4082,0.4082),\lambda=0$ / $u_2=(0.4082,-0.4082,0.5774,-0.5774),0.5$ / $u_3=(0.4082,0.4082,-0.5774,-0.5774),1.5$ / $u_4=(0.5774,-0.5774,-0.4082,0.4082),2$. 서로 수직(내적 0), 부호는 첫 비영 성분을 양수로. $L=U\Lambda U^\top$. **$x=(1,2,3,4)$는 고유벡터가 아니다.**
- S6 $\lambda$ = 그 방향의 거칢 ÷ $\lVert v\rVert^2$. 약분판($\times\sqrt6$)에서 거칢 $0,3,9,12$, 크기 제곱 모두 6, 몫이 $\lambda$. 부호가 바뀌는 간선 수도 $0,1,2,3$. **모드**=고유벡터 하나, **스펙트럼**=$\{0,0.5,1.5,2\}$. $\lambda=0$ 모드는 상수가 아니라 $\sqrt d$에 비례.
- S7 $c=U^\top x=(4.5898,-0.9856,-2.8167,-0.1691)$, $x=\sum c_ku_k$. 검산 둘: $\sum c_k^2=30=\lVert x\rVert^2$, $\sum\lambda_kc_k^2=12.4437$. 거칢의 95.6%가 $\lambda=1.5$ 모드에서 오는데 크기로는 26.4%뿐 → $x$는 부드럽지 않다. $U^\top x$가 논문이 말하는 "그래프 푸리에 변환".
- S8 **필터** = 모드마다 곱하는 배수표 $g$. **스펙트럼 합성곱** = 쪼개고($U^\top x$) 곱하고($g(\Lambda)$) 되돌리기($U$). $g(\lambda)=1-\lambda$면 결과가 $Sx=(3.1213,3.3284,0.7071,1.4142)$ — **모드에서 곱하기 = 정점에서 이웃 섞기**. 파라미터 4개(=$N$).
- S9 $U^\top U=I$ → $(U\Lambda U^\top)^k=U\Lambda^kU^\top$ → 배수표를 다항식으로 제한하면 $Ug(\Lambda)U^\top=g(L)$. $U$가 사라지고 희소 곱만 남는다. 파라미터 $K+1$. 대가: 배수가 $K$차 곡선 위에만 놓인다.
- S10 $K$-hop 국소성. $(L^2)_{34}=0$, $(L^3)_{34}=-0.25$. $K$층 쌓기 = $K$차 다항식.
- S11 두 조작. (1) 재척도 $\tilde L=\frac2{\lambda_{max}}L-I$ — 눈금을 $[-1,1]$로. G4는 $\lambda_{max}=2$라 $\tilde L=-S$(정확), G4○(5-고리)에서는 1.809. **이 물결은 03의 $\tilde A$ 물결과 뜻이 다르다.** (2) Chebyshev $T_0=1,T_1=y,T_k=2yT_{k-1}-T_{k-2}$ — 가운데 눈금에서도 값이 죽지 않아 계수 상쇄가 없다. $T_2(\tilde L)=2S^2-I$는 1-hop 세 쌍에서 0이고 2-hop 쌍 $(1,4),(2,3)$에 0.7071. G4는 **양쪽으로 갈리는 그래프**.
- S12 $K=1$ 절단 → $\theta'_0x-\theta'_1Sx$. 근사는 $\tilde L=L-I$ 하나뿐. 파라미터 2개. (02의 (a))
- S13 $\theta=\theta'_0=-\theta'_1$ → $\theta(I+S)x$. 부호를 같게 묶으면 $\theta Lx$가 되어 거칢을 꺼내는 쪽이 되므로 반대 부호가 식 (1)의 가정과 맞다. $I+S=2I-L$이라 눈금이 $2-\lambda$로 뒤집히고 최대 눈금 2 → $(I+S)^8x=(668.1,688.7,465.1,494.3)$. 파라미터 1개. (02의 (b))
- S14 **renormalization trick** = $I+D^{-1/2}AD^{-1/2}\to\tilde D^{-1/2}\tilde A\tilde D^{-1/2}$라는 화살표(치환). 자기 고리 $1\to1/3,1/2$, 간선 $0.5\to1/3$, $0.7071\to0.4082$. $v_1$의 자기/이웃 비가 $1.4142\to0.8165$로 **뒤집힌다**. $\hat Ax=(2.2247,2.6330,1.9082,2.8165)$ — 03과 같은 행렬. 식 (8) $Z=\hat AX\Theta$, 파라미터 $C\times F$. (02의 (d))
- S15 고쳐진 것: $\hat A\sqrt{\tilde d}=\sqrt{\tilde d}$, 최대 눈금 정확히 1. $\operatorname{spec}(\hat A)=\{-0.2287,0.1667,0.7287,1\}$(합 = 대각합 $5/3$). 대가 둘: 음수 눈금이 생긴다(G4의 장면), 1이 아닌 모드가 $\lvert\mu\rvert^k$로 죽는다($0.7287^8=0.0795$). 한 줄 근거: $\hat A=I-L(\tilde G)$, $\mu=1-\lambda(\tilde G)$ → $\mu\in(-1,1]$.
- S15 반증: $\hat A$의 네 눈금이 서로 다르므로 모드가 방향 하나씩. $\mu=1$ 모드 $\sqrt{\tilde d}$를 $L$의 네 모드로 쪼개면 성분이 **둘**(3.1547, −0.2188) → $\sqrt{\tilde d}$는 $L$의 고유벡터가 아니다 → $\hat A\ne Ug(\Lambda)U^\top$. 기저가 바뀐 자리는 사슬에서 S14 한 곳뿐이고, 이유는 그래프가 바뀌었기 때문.
- 파라미터 사슬: $4\to K{+}1\to2\to1\to C\times F$.

## 추론·불확실한 부분
- "받아 쓴다"고 밝힌 것: 대칭 행렬에 수직 고유벡터가 $N$개 있다는 사실, $UU^\top=I$, $T_k$가 $[-1,1]$ 안에서 크기 1을 안 넘는다는 것, $\operatorname{spec}(\hat A)$의 네 수를 찾는 방법. 나는 이것들을 **검산은 했지만 증명은 못 한다.**
- S11의 "둘째 곤란 — 계수가 서로 상쇄해야 한다"는 말은 따라갔지만, 왜 그것이 gradient 학습을 어렵게 하는지는 감으로만 안다. 그림이 이 대목을 안 다룬다.
- 행 평균 $\tilde D^{-1}\tilde A$의 고유값이 왜 실수로 남는지는 문서가 다루지 않는다고 밝혔고, 나도 모른다.
- $\lambda_{max}$를 "전체 고유분해 없이 근사할 수 있다"는 말은 받아 적었을 뿐 방법은 모른다.

## 정정이 있을 때
- 이전 이해(03 §2.3을 읽은 직후): "대칭으로 두면 고유벡터를 수직으로 잡을 수 있다"는 말은 그냥 수학적 취향 같았다. → 현재 이해: 수직이 깨지면 S7의 분해($x=\sum c_ku_k$)와 $\sum c_k^2=\lVert x\rVert^2$ 검산 자체가 성립하지 않는다. [05 S6 "되돌려 받는 것 하나"]
- 이전 이해(05 도입부): $\hat A$는 스펙트럼 필터의 특수한 경우일 것이다. → 현재 이해: **아니다.** $\hat A$는 원 그래프 $L$의 기저를 쓰지 않는다. 다른 그래프 $\tilde G$의 라플라시안을 뒤집은 것이다. [05 S15 반증]
