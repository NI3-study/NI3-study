## 1. 종착 이해 6개와 의존 사슬

현행 자료는 "MLP → AXW → (A+I)XW → ÂXW"를 커리큘럼처럼 쓰고 있다. 그러나 이 사슬은 **T3의 선수 조건일 뿐** 종착점이 아니다. 두 원문을 실제로 이해했다고 말하려면 다음 6개가 남아야 한다.

### T1. 순열 대칭성은 성질이 아니라 설계 제약이다
`[선]` 정점 번호는 내가 붙인 것 → `[선]` 인접 리스트의 저장 순서 → `[교]` 순서 불변 집계(합/평균/최대) vs 순서 의존 결합(concat)의 대비 → `[교]` $X'=PX$, $A'=PAP^\top$, $\hat A'=P\hat AP^\top$ → `[종]` 등가성 $\hat A'X'W=P(\hat AXW)$, 불변성 = readout이 $P$를 소거 → `[확]` 대칭이 아키텍처를 강제한다(CNN 평행이동 ↔ GNN 순열), geometric deep learning.
**왜 종착인가**: $W$ 공유, $\rho$ 선택, readout 존재 이유가 전부 이 하나에서 파생된다. 지금은 `01 §3`에 수식으로만 있고 조작 가능한 형태가 어디에도 없다.

### T2. 집계는 이웃 다중집합에서 무엇을 버릴지 고르는 일이다
`[선]` 이웃 값들은 순서 없는 주머니 → `[교]` $\{1,1,1\}$ vs $\{1\}$, $\{1,3\}$ vs $\{2,2\}$ — 집계마다 충돌 쌍이 다르다 → `[교]` 충돌 = 두 정점이 구별 불가 → `[교]` WL-1: 이웃 라벨 다중집합을 hash해 색을 반복 갱신 → `[종]` Appendix A — $c_{ij}=\sqrt{d_id_j}$면 GCN 정점식이 WL-1의 "미분 가능하고 파라미터화된 일반화"로 읽힌다. 단 논문의 표현은 *loosely speaking*이고, 합+선형변환은 injective hash가 아니다 → `[확]` GIN, 1-WL 상한 (Foundation 02).

### T3. $\hat A$는 하나의 연산자이고, 그 스펙트럼이 깊이의 운명을 정한다 ★가장 추상적
`[선]` 같은 연산을 반복하면 값이 평평해진다 → `[교]` 정점 위의 숫자 한 벌 = 그래프 신호. 어떤 패턴은 반복해도 잘 안 죽고 어떤 패턴은 빨리 죽는다 → `[교]` 잘 죽지 않는 패턴 = $L$의 고유벡터, 죽는 속도 = 고유값. $L=U\Lambda U^\top$, $U^\top x$ = 그래프 푸리에 → `[교]` $g_\theta(\Lambda)$ 직접 계산은 비싸고 기저가 그래프마다 다르다 → Chebyshev $K$차 = $K$-hop 국소 → `[교]` $K=1$, $\lambda_{max}\approx2$ → $\theta(I+D^{-1/2}AD^{-1/2})$ → `[종]` **이 연산자의 고유값이 $[0,2]$라서 깊게 반복하면 폭발/소실이 생긴다. renormalization은 스펙트럼을 죄는 치환이다** → `[확]` Appendix B의 깊이 저하, oversmoothing/oversquashing, spectral vs spatial 논쟁.
**현행 공백**: `02 §4`는 식 (3)~(8)을 순서대로 옮겨 적을 뿐, "고유벡터가 무엇처럼 생겼는가"를 볼 수 있는 대상이 하나도 없다. 논문이 직접 쓴 `[0,2]` 문장(원문 164행)이 해설에서는 "수치 불안정"으로만 요약돼 있어 T3이 통째로 암기 대상이 된다.

### T4. 손실 마스크와 계산 그래프는 다른 것이다
`[선]` 정답이 5%만 있다 → `[교]` forward는 전체 정점에서, 손실은 $\mathcal Y_L$에서만 → `[교]` 라벨 없는 정점은 손실에 없지만 $\hat A$ 경로 위에 있다 → `[종]` 식 (9)(10): gradient가 $\hat A$가 만든 경로를 거슬러 공유 $W$로 모인다. 논문의 전환은 그래프를 손실의 **벌점**(식 1)에서 forward의 **구조**로 옮긴 것이다 → `[확]` transductive ≠ inductive, 분할 누수 (Foundation 05).

### T5. 행렬 표기는 구현에 대한 거짓말이다
`[선]` $N\times N$은 거의 전부 0 → `[교]` 간선만 저장 → gather–sum → `[교]` $\hat AX$를 간선 순회로 다시 쓰기 → `[종]` $O(|E|FC)$ sparse×dense, full-batch 메모리는 그래프 크기에 선형, **$k$층의 정확한 미니배치는 $k$-hop 이웃 전체를 요구한다** → `[확]` 이웃 폭발, 샘플링 (Foundation 03).

### T6. 예측 단위가 마지막 대칭과 readout을 정한다
`[선]` 답이 몇 개 필요한가(정점마다/간선마다/그래프마다) → `[교]` 그때 남아야 할 표현은 무엇인가 → `[교]` 속성이 없는 쪽으로 pooling(간선→정점, 정점→간선, 전역) → `[종]` readout이 등가성을 불변성으로 바꾸는 지점이고, 정점·간선·전역이 서로 갱신하는 블록이 GCN보다 넓은 틀이다 → `[확]` 계층적 풀링, 링크 예측, 이종 그래프 (Foundation 04).

                          └─→ [선] 희소성 ──→ T5                    │

                                    │                                │
                    [교] AX=이웃 합 ─┴→ [교] A+I ─→ [교] 차수 정규화 ─┴→ T3
                                                        │
                    [교] 반복 적용 k (수용 영역 ∧ 값 붕괴) ┘

## 3. 전 사슬을 관통시킬 시각적 불변량

1. **정점 위의 숫자 한 벌 = 그래프 신호.** T1~T6 전부를 "이 연산이 신호에 무슨 짓을 하는가"로 통일할 수 있는 유일한 대상. 고유벡터도 결국 이것의 한 종류다.
2. **격자 ↔ 그래프 ↔ 간선 리스트 삼중 대응.** $A$ → $A+I$ → $\hat A$ → $\hat A^k$ → $T_k(L)$ → gather–sum까지 같은 격자 한 장으로 이어진다.
3. **두 축 규약** — 세로 = 정점, 가로 = 특성. 어디서나 $\hat A$는 위아래로, $W$는 좌우로 섞는다.
4. **재번호 토글 $P$** — 모든 그림에 붙는 공용 컨트롤. T1을 별도 그림이 아니라 상시 감각으로 만든다.
5. **반복 횟수 $k$ 하나** — 수용 영역·$\hat A^k$·층 수·값 붕괴가 같은 슬라이더를 공유해야 한다. 지금 $k$는 "덮인 범위"만 뜻한다.
6. **하나의 표준 그래프**(4정점 사슬 ↔ 허브 토폴로지 전환). 현행 3종이 서로 다른 그래프를 쓰는 것이 구조적 최대 결함이다.

## 4. 현행 인터랙티브 3종 비판

**공통.** (a) 전부 스칼라 특성이라 **특성 축·$W$·$\sigma$가 화면에 한 번도 등장하지 않는다**. 모임의 성공 기준 1번("$\hat A$와 $W$가 어느 축을 섞는가")을 그림이 뒷받침하지 못해, 체크포인트 1-3번이 그 공백을 *질문으로* 때우고 있다. (b) 재번호가 불가능해 세 그림이 공통으로 전제하는 T1이 조작 대상이 아니다. (c) 전부 연산자 **1회** 적용이다. $\hat A^2$도, 층 사이 $\sigma$도 없어 Q1("2층은 $\hat A^2XW$로 접히지 않는다")에 대응하는 시각물이 없다. (d) 손실·라벨·gradient가 없어 논문의 본론(T4)이 통째로 텍스트다. (e) 그래프가 셋 다 달라 값을 이어 나를 수 없다 — 체크포인트 3-3번은 "체크포인트 2의 허브 그래프에서 $k$를 올리면?"을 묻지만 **화면에서 확인할 수 없는 질문**이다.

**① message-passing.** $m=h_j$, 합 고정. $\rho$를 바꿀 수 없어 `01 §6` 표와 $\{1,3\}$/$\{2,2\}$ 충돌(= T2의 출발점)이 전혀 시각화되지 않는다. $v_1=v_4=6$이라는 핵심 우연도 진행자 노트에서만 살아난다.

**② normalization.** 셋 중 가장 낫다(실수값과 격차 배수를 정직하게 보여 준다). 그러나 $x_i=1$ 고정이라 **차수 효과만** 보여 줄 수 있다. 정규화가 동시에 스펙트럼 재조정이라는 사실, 반복했을 때의 거동, 진행자 노트가 요구하는 $\tilde D^{-1}\tilde A$와의 3자 비교가 모두 불가능하다. T3으로 가는 다리여야 하는데 다리가 끊겨 있다.

**③ receptive-field.** 가장 위험하다. **덮인 집합(✓/–)만 보여 주고 값의 붕괴를 보여 주지 않는다.** 결과적으로 "층이 깊을수록 많이 본다"는 인상을 만들고, 본문은 그 인상을 `01 오해 2`·Appendix B·oversmoothing으로 **반박하는 데 지면을 쓴다**. 게다가 사슬 그래프라 수용 영역이 온순하게 늘어 이웃 폭발(T5)도 가려진다. 그림이 교훈의 반대를 주장하는 경우다.

**총평**: 3종은 T3의 *선수 구간*(집계·자기 연결·차수·hop)만 덮는다. 종착 6개 중 화면에 존재하는 것은 **0개**다.

## 5. 우선순위

| 순위 | 만들 것 | 근거 |
|---|---|---|
| 1 | **재번호 토글 $P$** — 기존 3종에 공용 컨트롤로 소급 적용 | 전 사슬의 선수(T1), 비용 최소, 현재 커버리지 0 |
| 2 | **깊이의 두 얼굴** — ③을 수용 영역 + 값 붕괴 2패널로 개조, 허브 토폴로지 전환 추가 | 오개념 생산 그림을 Appendix B 교훈으로 뒤집음. T3·T5 동시 진입 |
| 3 | **스펙트럼 사슬** — 고유벡터를 "정점 위의 패턴"으로, 고유값을 "죽는 속도"로, $[0,2]$ → renormalization을 눈금 하나로 | 난이도×공백 최대. 논문의 본체(T3) |
| 4 | **집계 선택기** — ①에 $\rho$ 전환과 충돌 쌍 제시 | T2, Foundation 02의 출구 |
| 5 | **두 축 분리 패널** — $N\times F$와 $W$, $\sigma$가 처음 등장 | 성공 기준 1번, 소형 |
| 6 | **라벨 마스크와 gradient 경로** | 논문의 본론(T4) |
| 7 | **희소 gather–scatter / 이웃 폭발** | T5, Foundation 03 예고 |
| 8 | **readout·pooling** | T6. Foundation 01 범위 밖이나 04 이전 필수 |

가로지르는 전제: **1~8을 모두 하나의 표준 그래프 위에서** 만든다. 기존 접근성 규약(숫자 병기, 굵기·기호 병용, CSS 변수 색, 타이머 없음)은 그대로 유지한다.
