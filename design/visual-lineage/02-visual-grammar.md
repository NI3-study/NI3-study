# 02 · 시각 문법과 계보 구조

**역할 2 산출물.** 개별 그래픽 목록이 아니라, 한 벌의 원시형(primitive)이 일곱 국면을 관통하며 어떻게 변형되는지에 대한 규약이다.

관통 대상 일곱 국면: ①그래프 데이터 표현 → ②메시지 패싱 → ③정규화 전파 $\hat A=\tilde D^{-1/2}\tilde A\tilde D^{-1/2}$ → ④층 쌓기와 수용 영역 → ⑤스펙트럼 필터 → ⑥반지도 학습과 손실 → ⑦한계(oversmoothing·transductive).

기존 자산 제약을 그대로 승계한다. `gnn-visuals.js`는 타이머·애니메이션을 쓰지 않고 사용자 조작에만 반응하며, `extra.css`는 색을 `focus / active / idle / out` 네 **역할** 상태로만 정의한다. 새 문법은 이 네 상태를 확장하지 않는다.

---

## 1. 후보 원시 체계 3안

**A안 — 그래프 우선(Graph-first).** 노드-링크 다이어그램 하나가 언제나 무대의 주인공이고, 행렬·수식·스펙트럼은 그림 위 오버레이나 아래 표로 붙는다. 현재 사이트가 사실상 쓰는 방식이다. 장점은 진입 비용이 0이라는 것. 한계는 ⑤스펙트럼과 ③정규화의 "행렬 축" 사고가 언제나 부속물로 밀려나, 논문이 실제로 요구하는 *정점 축 ↔ 특성 축* 구분이 그림 안에서 한 번도 1급 시민이 되지 못한다.

**B안 — 이중 표면(Dual Surface).** 모든 화면이 **원반 표면**(그래프)과 **격자 표면**(텐서) 두 장으로만 구성되고, 같은 값이 두 표면에 동시에 존재한다. 원반 $v_i$와 격자의 $i$행은 영구히 같은 대상이며 같은 역할색을 공유한다. 개념이 바뀌면 그림이 교체되는 게 아니라 *두 표면 중 어느 쪽이 커지는지*만 바뀐다.

**C안 — 블록 대수(Block Algebra).** 모든 것을 직사각형 블록으로 환원해 $\hat A\,H\,W$를 블록 곱 도식으로 그린다. 차원 정합과 $O(|E|FC)$ 복잡도를 가장 정직하게 보여 준다. 그러나 ②메시지 패싱의 "이웃 하나가 보낸 값"이라는 국소 서사가 블록 안에서 소멸하고, 첫 프레임이 이미 추상적이라 무조작 학습 조건을 어긴다.

## 2. 선택: B안 (이중 표면)

- **계보가 성립한다.** A안은 ⑤에서, C안은 ②에서 각각 문법이 끊긴다. B안만 일곱 국면 전부를 같은 두 표면으로 덮는다. ⑤스펙트럼조차 새 그림이 아니라 "격자의 **행 정렬 규칙**만 hop 정렬에서 주파수 정렬로 바꾼 것"이 된다.
- **논문의 핵심 문장이 곧 레이아웃이다.** `03_bridge` 12절의 "왼쪽 $\hat A$는 정점 축을, 오른쪽 $W$는 특성 축을 섞는다"가 두 표면의 존재 이유 그 자체다.
- **C안의 장점을 흡수한다.** 격자 표면은 필요할 때 블록으로 축약할 수 있다(전이규칙 T1). 역방향—블록에서 원반으로의 복원—은 불가능하므로 C안을 기반으로 삼을 수 없다.
- **기존 3종 시각화가 그대로 B안의 부분집합**이다. 재작성이 아니라 격자 표면 추가만으로 승격된다.

## 3. 시각 알파벳: 원시형 6 + 축 3

| 기호 | 형태 | 고정 의미 | 허용 변주 |
|---|---|---|---|
| **P1 원반** | 테두리 있는 원 | 정점 정체성 1개 | 크기(차수), 역할색, 점선 테두리(범위 밖) |
| **P2 칸** | 작은 정사각형 | 스칼라 1개 (특성·가중치·확률·고유벡터 성분 공통 단위) | 채움 농도, 빗금(음수), 숫자 표기 |
| **P3 현** | 두 원반을 잇는 선 | 간선 1개 | 굵기(가중치), 점선(비활성), 실선 |
| **P4 화살** | 방향 있는 짧은 선 | 흐름 1건 (메시지 또는 그래디언트) | 방향, 강조 |
| **P5 테** | 원반을 감싸는 폐곡선 | 집합 경계 (이웃·수용 영역·라벨 집합 $\mathcal Y_L$) | 반지름, 겹침 수 |
| **P6 기둥** | 세로 블록 | 학습 파라미터 $W$ | 폭(출력 채널 수), 층 번호 |

**축 규약(세 개, 예외 없음).**
- **가로 = 특성 축** $F$. 칸이 가로로 늘어나면 언제나 채널이다.
- **세로 = 정점 축** $N$. 격자 $i$행은 원반 $v_i$이며, 순서는 사이트 전체에서 영구 고정($v_1 \ldots v_N$).
- **화면 왼→오 진행 = 층/시간** $l$. 층이 늘면 오른쪽으로 자란다. 위→아래로 층을 쌓는 표현은 금지(정점 축과 충돌).

역할색은 **정체성이 아니라 역할**이다. `focus`=지금 갱신되는 정점, `active`=이번 계산에 참여, `idle`=비참여, `out`=수용 영역 밖. 같은 정점이 화면마다 색을 바꾸는 것은 정상이며 의도다.

## 4. 개념 → 원시형 사상

| 개념 | 사상 |
|---|---|
| 정점 정체성 | P1 (위치·번호 영구 고정) |
| 정점 상태 $h_i^{(l)}$ | P1 안의 숫자 + 격자 $i$행의 P2 띠 |
| 간선·가중치 $\hat A_{ij}$ | P3 굵기 + 간선 라벨 숫자 |
| 방향·메시지 $m_{j\to i}$ | P4 (무방향 그래프에서도 메시지는 항상 방향을 가진다) |
| 텐서와 축 | P2 격자 + 축 규약 3 |
| 학습 변환 $W^{(l)}$ | P6 (항상 격자 **오른쪽**에 붙는다) |
| 집계 $\rho$ | 여러 P4가 한 P1로 수렴 + 결과 배지 |
| 층/시간 | 가로 진행 + P6 번호 |
| 라벨·손실 | P5(=$\mathcal Y_L$) + 격자 해당 행 옆 정답 칸 |
| 스펙트럼 모드 | 정렬 규칙이 바뀐 격자 + P2 부호(빗금) |

**스펙트럼 처리가 이 문법의 시험대다.** 고유벡터 $u_k$는 새 도형을 얻지 못한다. 같은 원반 배치 위에 P2의 부호(채움/빗금)를 얹은 것이 하나의 모드이고, 격자에서는 행 정렬만 주파수 순서로 바뀐다. 체비셰프 차수 $K$는 P5의 반지름으로, $K$-국소성은 "$K$겹 테 밖으로는 P4가 나가지 않는다"로 읽힌다. 이로써 ⑤와 ④는 같은 그림의 두 읽기가 된다.

## 5. 전이 규칙 (5 연산자)

문법이 계보인 이유는 다음 다섯 연산 외의 변화를 금지하기 때문이다.

- **T1 변형(transform).** 원반 표면 ↔ 격자 표면. 한쪽을 강조하면 다른 쪽은 축약되지만 **사라지지 않는다.** 대응 요소는 항상 같은 역할색으로 동시 강조된다.
- **T2 직렬화(serialize).** 한 계산을 순서 단계로 분해한다(메시지→집계→갱신). 단계가 늘어도 원반 위치·정점 순서는 불변이며, 이전 단계의 결과는 화면에 남는다.
- **T3 병렬화(parallelize).** 같은 연산을 모든 정점에 동시 적용함을 보인다. 초점 정점의 P4 묶음을 나머지 정점에 **흐린 동일 패턴**으로 복제한다. 새 도형 도입 금지 — 가중치 공유의 시각적 증명이다.
- **T4 심화(deepen).** 오른쪽으로 한 칸 자란다. 새 P6 기둥 1개 + P5 반지름 1 증가. 그래프 레이아웃은 절대 다시 그리지 않는다.
- **T5 증식(multiply).** 특성 축을 1→$C$로 넓힌다. P2 칸이 가로로 늘어날 뿐 세로는 그대로다. ⑦한계 국면은 T4를 과하게 적용했을 때 P2 띠들이 서로 닮아 가는 것으로 표현한다(별도 그래픽 없음).

## 6. 절대 불변 / 가변

**변하면 안 되는 것.** ①정점의 화면 좌표와 번호, ②격자 행 순서(=정점 순서), ③가로=특성·세로=정점·왼→오=층이라는 축 의미, ④역할색 네 가지의 의미, ⑤$W$는 언제나 오른쪽, 집계 연산자는 언제나 왼쪽, ⑥P1~P6의 형태-의미 결합, ⑦색 단독 인코딩 금지(숫자·기호·굵기·점선 중복), ⑧타이머·자동 재생 금지.

**변해도 되는 것.** 두 표면의 상대 크기, 강조 대상, 숫자 소수 자릿수, 그래프 예제 규모(단 ①의 좌표 관습은 유지), 라벨 문구, P5 겹침 수, 특성 채널 수.

## 7. 컨트롤 규약

- **첫 프레임이 완결이다.** 조작 없이도 기본 상태(초점 $v_1$, 단계 0, $k=0$, 원본 $A+I$)가 한 문장을 완결적으로 가르쳐야 한다. 조작은 *심화*이지 *해금*이 아니다.
- **뷰당 컨트롤 최대 2개**, 각각 하나의 의미 축만 담당한다.
- **허용 컨트롤 3종뿐:** (a) 초점 선택 — 순열 등가성을 보여 주는 변주, (b) 단계/층 진행 — T2·T4의 노출, (c) 대조 토글 — 정확히 두 값의 비교($A+I$ 대 $\hat A$, sum 대 mean, 정점 정렬 대 주파수 정렬).
- **금지:** 레이아웃 전환, 장식 토글, 재생 버튼, 결과가 달라지지 않는 선택지.

이 규약을 지키면 독자는 문서 5개를 지나는 동안 새 시각 언어를 배우지 않는다. 배우는 것은 같은 여섯 도형이 다섯 연산으로 변해 가는 하나의 이야기뿐이다.
