# 03. 적대적 교육학 리뷰 — 어디서 가짜 정신모형이 생기는가

## 0. 판정 요약

현재 텍스트는 **오해를 문장으로 반박**하지만(01 §11, 02 §13), 학습자가 그 오해를 **틀린 예측으로 드러낼 기회**를 주지 않는다. 세 데모는 모두 "이미 맞는 답을 보여 주는" 확인 장치라서, 반증 압력이 0이다. 더 나쁜 것은 데모 2·3이 텍스트의 주장과 **수치적으로 어긋난다**는 점이다. MLP·자료구조 배경 학생은 GNN을 "시작 정점에서의 BFS"로 압축해 버리는데, 현재 데모 3개 중 2개가 바로 그 모형을 강화한다.

## 1. 가짜 정신모형 — 교육적 이득 순위

### ① 동기 갱신 + 파라미터 공유 (최상위 이득)

**생길 오해:** "메시지 패싱은 중심 정점 하나를 정해 이웃을 훑는 절차다." 자료구조 배경에서 `neighbors(i)` 순회는 즉시 BFS로 매핑된다.

**진단:** 데모 1은 라디오 버튼으로 *중심 정점을 고르게* 하고 그 정점만 갱신한다. 데모 3은 아예 v1 기준 BFS 거리다. 두 데모 모두 "한 층에서 **모든** 정점이 **동시에** 갱신된다"를 한 번도 보여 주지 않는다. 결정타는 세 데모 중 어디에도 $W$가 없다는 것이다 — 03 §6이 "가중치 공유가 중요한 이유"를 절 하나로 다루는데, 시각적 대응물이 전무하다. 공유되지 않은 $W_i$가 무엇을 망가뜨리는지 볼 수 없으면 공유는 "논문이 그렇게 했다"로 남는다.

### ② $\hat A = I - \tilde L$ 이라는 누락된 고리 (오버스무딩의 유일한 메커니즘)

**생길 오해:** "집계는 정보를 모으는 일이고, 오버스무딩은 깊게 쌓으면 생기는 별개의 사고(事故)다."

**진단:** 02 §4는 $L = I - D^{-1/2}AD^{-1/2}$를 쓰고, §5는 $\hat A$를 쓰는데, **둘이 같은 대상의 앞뒷면이라는 말을 하지 않는다.** 그래서 $\hat A$ 반복 = 거듭제곱 반복 = 지배 고유벡터($\propto\sqrt{\tilde d}$)로의 수렴이라는 사슬이 끊긴다. 03 §8과 02 §11은 오버스무딩을 *용어로만* 도입한다. 학습자는 예측할 수 없고 암기만 한다. 고유값 스펙트럼을 한 번만 보여 주면 renormalization trick(왜 $[0,2]$를 $(-1,1]$로 줄였는가)과 오버스무딩이 **같은 그림 하나로** 설명된다. 이득 대비 비용이 가장 좋은 항목.

### ③ 순열 등가성 — 반례가 없다

**생길 오해:** "순열 등가성 = 순서를 안 쓴다" 또는 "정점을 차수순으로 정렬하면 되지 않나?"

**진단:** 01 §3과 03 §7은 $(PX)W = P(XW)$를 **대수적으로 증명**한다. MLP를 아는 학생은 이미 아는 결합법칙이라 고개만 끄덕이고 넘어간다. 틀린 쪽(순서 의존 집계)이 **실제로 다른 숫자를 뱉는 장면**이 없으므로, 등가성은 획득된 제약이 아니라 통과한 문장이 된다. 정준 정렬이 왜 탈출구가 아닌지(동률 차수, 국소 정렬의 전역 불일치)는 어느 문서도 건드리지 않는다.

### ④ 수용 영역 ≠ 영향력

**생길 오해:** "3층이면 3-hop 정점이 내 표현에 들어온다"를 **균등한 기여**로 읽는다.

**진단:** 데모 3은 ✓/– 이진 표시다. 이진 표시는 정의상 영향력 크기를 표현하지 못한다. 실제 기여는 $\prod 1/\sqrt{\tilde d}$로 감쇠하므로 허브를 경유한 3-hop 정점은 사실상 0이다. 더 심각한 결함: 데모 3의 그래프는 트리형이라 수용 영역이 1→3→5→7로 **선형 증가**한다. 그런데 03 §8과 04 해설7은 "이웃 수가 급격히 늘어난다(이웃 폭발)"고 쓴다. **데모가 텍스트를 반증하고 있다.** 병목 간선이 없으므로 oversquashing(먼 정보가 좁은 간선에 압축되는 현상)은 관찰 자체가 불가능하다.

### ⑤ 대칭 정규화 ≠ 평균

**생길 오해:** "정규화는 차수로 나누는 것, 즉 평균이다."

**진단:** 데모 2는 `raw` / `sym` **2지 선택**이다. 정확히 텍스트(02 §5, 04 해설3)가 경고하는 오해 — "$\tilde D^{-1}\tilde A$와 같지 않다" — 를 확인할 제3의 보기가 없다. 숫자로 보면: 평균 집계는 모든 정점 출력이 정확히 1.0(격차 1.00배), 대칭 정규화는 1.41 대 0.82(격차 **1.72배**), 원본은 2.50배다. 세 값을 나란히 놓을 때만 "대칭 정규화는 차수 격차를 *줄이되 지우지 않는다*"가 성립한다. 또한 모든 $x_i=1$로 고정했기 때문에 **송신자 차수 감쇠**($1/\sqrt{\tilde d_j}$: 허브가 보내는 메시지가 약해진다)가 원리적으로 보이지 않는다.

### ⑥ 스펙트럼→공간 유도의 "선택" 지점

**진단:** 02 §4는 식 (3)→(8)을 매끄러운 치환 사슬로 제시한다. 실제로는 (a) $K=1$, (b) $\theta'_0=-\theta'_1$, (c) $\lambda_{max}\approx2$, (d) $\hat A \ne I + D^{-1/2}AD^{-1/2}$ 인 연산자 교체 — 네 곳이 **필연이 아닌 선택**이다. §4.3에 한 줄 경고가 있지만 (d)에는 없다. 학습자는 "GCN은 스펙트럼 합성곱과 동치"라는 강한 오해를 얻는다.

### ⑦ Transductive

**생길 오해:** 양극단으로 갈린다. "테스트 데이터를 봤으니 반칙이다" 또는 "라벨 없는 정점도 학습 데이터다."

**진단:** 02 §1과 03 §10은 정의를 잘 구분하지만, **작동적 귀결**을 묻지 않는다: 테스트 시점에 정점 하나를 추가하면 기존 정점들의 예측이 바뀌는가? (바뀔 수 있다.) MLP 세계에서 표본은 독립이므로 이 질문이 학습자 머릿속에 아예 없다.

### ⑧ 경험적 주장 — 숨은 변수는 homophily

**진단:** Table 3의 MLP 46.5 대 GCN 70.3을 두 문서 모두 "이 데이터·분할에 한정"이라고 제한한다. 옳지만 **불충분**하다. 차이를 만든 성질의 *이름*(인용 간선의 높은 label homophily, Cora 기준 약 0.8)이 없으면, 학습자는 "그래프는 대체로 +20점"이라는 규칙을 들고 자기 과제로 간다. 04 문제 6-3의 간선 셔플 ablation이 옳은 방향이지만 손으로 할 수 없다.

### ⑨ node/edge/global 라우팅

**진단:** 01 §9는 세 갈래 갱신 흐름을 글머리표 3줄로만 다루고 그림이 없다. GCN은 정점만 갱신하므로, 학습자는 "GNN = GCN"으로 축약하고 간선 특성을 $A$의 가중치로 밀어 넣는 오답을 만든다.

## 2. 계보 단계별 학습 증거 — 결과를 보기 *전에* 예측시킬 것

| 계보 단계 | 사전 예측 요구 | 오답이 드러내는 모형 |
|---|---|---|
| $XW$ → $AXW$ | 허브와 잎의 출력 크기 대소 | 집계를 크기 중립으로 봄 |
| $A$ → $A+I$ | 자기 연결 제거 시 어느 정점 값이 가장 크게 변하는가 | 자기 정보를 자동 보존으로 오해 |
| 합 → 대칭 정규화 | 평균/대칭/원본 세 보기의 출력 **순위와 격차 배수** | 정규화=평균 |
| $\hat A$ → $\hat A^k$ | $k{=}10$에서 정점별 값이 *어디로* 수렴하는가 | 오버스무딩=막연한 성능 저하 |
| 1층 → 2층 | 2-hop 정점 v8의 기여가 1-hop v2의 몇 %인가 | 수용 영역=균등 영향 |
| 등가성 | 정점 재번호 후 출력 행이 어떻게 재배열되는가 / 순서 의존 집계는 어떻게 깨지는가 | 정렬로 해결 가능하다는 믿음 |
| 공유 $W$ | $W_i$를 분리하면 파라미터 수와 새 정점 처리에 무슨 일이 나는가 | 공유를 관행으로 봄 |
| transductive | 새 정점 1개 추가 시 **기존** 예측 변화 여부 | 표본 독립성 가정 |
| Table 3 | homophily를 낮추면 MLP–GCN 곡선이 교차하는 지점 | "그래프는 항상 이득" |

예측은 **숫자 또는 대소 관계**여야 한다. "설명하라"는 오답이 드러나지 않아 증거가 되지 못한다.

## 3. 시각화 시스템의 실패 모드

1. **단일 초점 편향.** 중심 정점을 고르게 하는 UI는 BFS 오해를 제도화한다. 기본 상태는 전 정점 동시 갱신이어야 하고, 초점은 *강조*일 뿐 *계산 범위*가 되어서는 안 된다.
2. **이진 부호화.** ✓/– 는 연속량(영향력, 가중치, 유사도)을 표현할 수 없다. 감쇠를 보여야 할 곳에 포함/불포함을 쓰면 틀린 모형을 만든다.
3. **편리한 그래프.** 트리·저차수 예제는 이웃 폭발, 병목, 수렴을 모두 관찰 불가능하게 만든다. 데모 그래프는 주장하려는 현상을 **담을 수 있어야** 한다.
4. **2지 대조.** 올바른 것 대 명백히 나쁜 것의 2지 선택은 "중간 대안"(평균 집계)을 지워 버려 잘못된 이분법을 만든다.
5. **파라미터 없는 GNN.** $W$와 $\sigma$가 데모에 전혀 없으면 학습 가능성이 그림에서 증발한다.
6. **텍스트–데모 모순.** 위 ④·⑤처럼 서로 어긋나면 학습자는 조용히 그림을 믿는다.
7. **확인 편향형 상호작용.** 조작해도 항상 "맞는 그림"만 나오면 반증이 불가능하다. 틀린 설정(비공유 $W$, 순서 의존 집계, 정규화 없음)을 **선택 가능한 상태로** 둬야 한다.

## 4. 반증 체크 — 시스템 완성 후 실행

- **BFS 체크:** "2층 GCN 계산에서 갱신되는 정점은 몇 개인가?" 다수가 "수용 영역 내부"라 답하면 ①이 남아 있다.
- **평균 체크:** "$\hat A$의 행 합은 1인가?" 아니오(예: 0.82, 1.41)를 근거와 함께 말하지 못하면 ⑤ 실패.
- **감쇠 체크:** 3-hop 정점 기여의 크기 순서를 못 매기면 ④ 실패.
- **스펙트럼 체크:** "왜 $I+D^{-1/2}AD^{-1/2}$가 아니라 $\hat A$인가"에 "고유값 범위" 없이 답하면 ②·⑥ 실패.
- **이식 체크:** 낮은 homophily 그래프에서 GCN < MLP를 예측하지 못하면 ⑧ 실패.
- **역방향 체크:** 각 시각화에 대해 "이 그림이 거짓이라면 화면에서 무엇이 달라 보이는가"에 답할 수 없다면, 그 시각화는 아무것도 가르치지 않는다.

## 5. 우선순위

②(스펙트럼 한 장) → ①(동시 갱신 + $W$ 토글) → ⑤(3지 정규화 대조) → ④(영향력 히트맵 + 병목 그래프) → ③(순서 의존 집계 반례) → ⑧(homophily 슬라이더). ⑥·⑦·⑨는 텍스트 수정으로 대부분 회수 가능하므로 시각화 예산을 쓰지 않는다.
