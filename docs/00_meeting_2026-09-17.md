## 3. 인터랙티브 체크포인트 { #checkpoints }

세 체크포인트는 모두 **사이트에 이미 있는 인터랙티브를 직접 조작한 결과**를 묻는다.
설명자가 조작하고, 답이 갈리면 그때 접힌 노트를 편다.

### 체크포인트 1 — 메시지 패싱 4단계 { #cp1 }

**위치**: [01 §5.4](01_gnn_gentle_guide.md#viz-message-passing)
**조작**: 중심 정점을 `정점 1`로 두고 ① → ④까지 넘긴다. 그다음 중심 정점만 `정점 4`로 바꾼다.

1. ④에서 정점 1의 값은 **6**이다. 중심 정점을 4로 바꿔도 값은 **6**이다. 두 정점은 특성도 이웃 수도 다른데 왜 같은가?
2. ③ 화면에 “합은 순서에 무관하다”가 나온다. 이 문장이 **보증하는 것**과 **보증하지 않는 것**을 각각 하나씩 말하라.
3. 이 인터랙티브 어디에도 $W$와 $\sigma$가 없다. 그러면 지금 계산한 것의 정체는 무엇인가?

??? note "진행자 노트 — 체크포인트 1"
    1. $v_1 = 1 + (2+3) = 6$, $v_4 = 4 + 2 = 6$. **합 집계는 “이웃이 많다”와 “값이 크다”를 같은 축으로 뭉갠다.**
       네 정점을 다 넘겨 보면 $6, 7, 4, 6$이고 이는 [01 §7](01_gnn_gentle_guide.md#ax-hand-calc)의 $(A+I)X$와 정확히 같다.
       → 여기서 자연스럽게 “그럼 차수를 어떻게 다룰까”가 나오고, 체크포인트 2로 넘어간다.
    2. 보증: 인접 리스트에 이웃이 어떤 순서로 저장돼 있든 결과가 같다(순열 등가성, [01 §3](01_gnn_gentle_guide.md#permutation)).
       보증하지 않음: 서로 다른 이웃 집합이 서로 다른 값을 준다는 것. $\{1,3\}$과 $\{2,2\}$는 합이 둘 다 4다([01 §6](01_gnn_gentle_guide.md#aggregation)).
       이 구분이 Foundation 02(WL·GIN)의 출발점이다.
    3. $(A+I)X$까지만 계산했다. **아직 학습되는 것이 하나도 없다** — [01 오해 3](01_gnn_gentle_guide.md#misconceptions).
       학생이 “여기까지가 GNN”이라고 말하면 바로 잡는다.

### 체크포인트 2 — $A+I$ 대 $\hat A$ 숫자 비교 { #cp2 }

**위치**: [02 §5](02_kipf2017_gcn_guide.md#viz-normalization)
**조작**: 라디오를 `원본 A + I` ↔ `대칭 정규화 Â`로 번갈아 바꾸고, 아래 표와 마지막 줄의 **“차수 격차”** 를 본다.
(허브 $v_1$의 차수는 5, 잎들은 2, 모든 특성은 1로 고정돼 있다.)

1. 원본에서는 출력이 각각 **5, 2, 2, 2, 3, 2**이고 격차가 **2.5배**다. 정규화하면 **1.4069 / 0.8162 / 0.9998 / 0.9082**, 격차 **약 1.724배**다.
   격차가 1배가 되지 않았다. 대칭 정규화가 하는 일을 한 문장으로 **정정**하라.
2. 격차를 정확히 1로 만들려면 행 평균 $\tilde D^{-1}\tilde A$를 쓰면 된다. 그러면 무엇을 잃는가?
3. $v_5$의 출력이 0.9998이다. 왜 딱 1이 아닌가?

??? note "진행자 노트 — 체크포인트 2"
    1. “차수 효과를 **제거**한다”가 아니라 **완화**한다. 허브는 정규화 후에도 더 많은 항을 더한다.
       계수는 $\hat A_{ij} = 1/\sqrt{\tilde d_i \tilde d_j}$이고, 행 합 $\sum_j \hat A_{ij}$는 일반적으로 1이 아니다([02 §5](02_kipf2017_gcn_guide.md#self-loop-normalization)).
    2. **이웃 수 자체가 신호일 때** 그 신호를 잃는다([01 §6 표](01_gnn_gentle_guide.md#aggregation)).
       또 $\tilde D^{-1}\tilde A$는 비대칭이라 무방향 그래프의 대칭성과 spectral 해석이 달라진다.
       “어느 쪽이 정답인가”가 아니라 **무엇을 버릴지 고르는 설계 선택**이라는 게 요점이다.
    3. $v_5$는 차수 3, 이웃은 $v_1$(차수 5)과 $v_6$(차수 2)이다.
       $\tfrac13 + \tfrac1{\sqrt{15}} + \tfrac1{\sqrt6} \approx 0.3333 + 0.2582 + 0.4082 = 0.9998$.
       1에 가까운 건 우연이다. 이 계산을 그대로 4정점으로 옮긴 것이 [04 문제 3](04_exercises.md#p3)·[02 §6](02_kipf2017_gcn_guide.md#hand-calc)이다.

### 체크포인트 3 — $k$층의 수용 영역 { #cp3 }

**위치**: [03 §8](03_bridge_mlp_to_gcn.md#receptive-field)
**조작**: 슬라이더를 $k=0 \to 3$으로 옮기며 “수용 영역 크기”와 ✓ / – 표시를 읽는다.

1. $k=0$은 1/8, $k=1$은 3/8, $k=2$는 5/8, $k=3$은 7/8이다. **$v_8$만 $k=3$에서도 `–`** 다. 왜인가?
2. 화면 맨 아래 주의 문장이 “정확히 거리 $k$가 아니라 거리 $k$ 이하”라고 한다. 이 차이를 만드는 원인 하나를 식에서 짚어라.
3. 이 그래프는 사슬에 가까워 수용 영역이 천천히 넓어진다. 체크포인트 2의 **허브가 있는 그래프**에서 $k$를 올리면 무슨 일이 벌어지나?

??? note "진행자 노트 — 체크포인트 3"
    1. $v_8$은 $v_1$에서 4-hop이다. 포함하려면 $k=4$가 필요하다. 각 정점 안의 숫자가 곧 hop 거리다.
    2. **자기 연결 $A+I$**. 그래서 0·1·2-hop 정보가 함께 섞인다 — [01 §8](01_gnn_gentle_guide.md#depth), [02 오해 “두 층이면 정확히 2-hop”](02_kipf2017_gcn_guide.md#misconceptions).
    3. 허브를 한 번 거치면 2~3층 만에 거의 전 그래프가 수용 영역에 들어온다.
       그래서 깊이를 늘리는 비용은 파라미터 증가만이 아니라 **이웃 폭발**(미니배치 곤란)이다 — [02 §12 한계](02_kipf2017_gcn_guide.md#limitations).
       [Appendix B](02_kipf2017_gcn_guide.md#depth-appendix-b)에서 2~3층이 가장 좋았고,
       “oversmoothing”은 그 저하를 단독으로 설명하는 원 논문의 결론이 **아니다**([04 문제 7](04_exercises.md#p7) 4번).
       이 갈래 전체가 Foundation 02·03의 주제다.

## 4. 개념 질문 4개 { #questions }

블록 사이 시간이 남을 때, 또는 E 블록에서 Q3·Q4를 쓴다. 노트는 답이 갈린 **뒤에** 편다.

**Q1.** [GCN 한 층](03_bridge_mlp_to_gcn.md#gcn-one-layer) $\sigma(\hat A H W)$에서, $(\hat A H)W$로 계산하는 것과 $\hat A(HW)$로 계산하는 것은 같은 결과인가? 층 사이에 $\sigma$가 들어가면?

??? note "진행자 노트 — Q1"
    결과는 같다(결합법칙, [03 §2](03_bridge_mlp_to_gcn.md#start-mlp)). 하지만 **비용이 다르다**:
    출력 채널이 작으면 $HW$를 먼저 해서 좁힌 뒤 전파하는 쪽이 싸다.
    $\sigma$가 끼면 이야기가 달라진다 — 2층 GCN은 $\hat A^2 X W$로 축약되지 **않는다**.
    비선형이 없으면 여러 층이 하나로 접힌다는 MLP 지식과 같은 이야기다.
    덧붙여, $W$는 정점마다 있는 게 아니라 **전부 공유**된다는 점을 여기서 다시 확인한다([03 §6](03_bridge_mlp_to_gcn.md#weight-sharing)).

**Q2.** 라벨이 5%뿐이라면 나머지 95% 정점은 학습에 쓸모없는 데이터인가?

??? note "진행자 노트 — Q2"
    아니다. 손실에는 안 들어가지만 forward 전파에 전부 참여한다 — 특성을 제공하고, 메시지 경로가 되고, 라벨 있는 정점의 이웃이 된다([02 §1](02_kipf2017_gcn_guide.md#semi-supervised-setup), [03 §9](03_bridge_mlp_to_gcn.md#unlabeled-nodes)).
    단, 이건 **학습 때 그 정점들을 이미 본다**는 transductive 가정이 깔린 이야기다([03 §10](03_bridge_mlp_to_gcn.md#transductive)).
    새 정점·새 그래프 일반화는 별도 평가가 필요하다.

**Q3.** [Table 3](02_kipf2017_gcn_guide.md#propagation-comparison)에서 Citeseer 기준 MLP 46.5 → GCN 70.3이다. 이 숫자가 증명하는 것과 증명하지 않는 것은?

??? note "진행자 노트 — Q3"
    증명: **그 인용 네트워크·그 분할·그 전처리에서** 간선이 분류에 유용했다.
    증명하지 않음: 모든 데이터에서의 우월성, 두 모델의 튜닝 공정성, 간선이 잡음이거나 homophily가 없는 데이터에서의 결과([04 해설 6](04_exercises.md#solutions)).
    결정적 후속 질문: **간선을 무작위로 섞는 ablation**을 넣으면 무엇이 분리되는가?
    표를 읽는 규칙 자체는 [02 §9 실험을 읽는 법](02_kipf2017_gcn_guide.md#experiments)에 정리돼 있다 — 고정 분할의 단일 숫자만 보지 않는다.

**Q4.** “우리 데이터를 그래프로 만들면 GCN이 MLP보다 잘할 것이다.” 이 문장을 **반증 가능한 실험**으로 바꾸면?

??? note "진행자 노트 — Q4"
    최소 조건 네 가지: ① 같은 특성·같은 분할을 쓰는 MLP 기준선 고정, ② 간선만 바꾸는 조작(추가 / 셔플), ③ 성공 기준을 **숫자로 미리** 선언, ④ 분할 전 누수 점검([04 해설 8](04_exercises.md#solutions)).
    여기서 나온 답을 그대로 아래 산출물의 “다음 실험” 칸에 옮긴다. **이 질문이 오늘의 출구다.**
