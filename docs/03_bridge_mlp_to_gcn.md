# MLP에서 GCN으로 가는 다리

> **이 문서가 처음으로 하는 것** — 인접 행렬 $A$에서 정규화 연산자 $\hat A=\tilde D^{-1/2}\tilde A\tilde D^{-1/2}$까지를 한 단계씩 **만든다**. [01 §8](01_gnn_gentle_guide.md#a-hat)이 정의로 준 $\hat A$가 왜 그 모양인지가 여기 있고, 이것을 그대로 쓰는 곳이 [02 논문 해설](02_kipf2017_gcn_guide.md)이고, 그 사이에 논문이 식 (2)를 적은 **뒤** 두 쪽에 걸쳐 되짚은 유도를 걷는 [05 스펙트럼 다리](05_spectral_bridge.md)가 온다. 읽는 순서는 이 문서가 두 번째다.

긴 유도 대신 “이미 아는 MLP 한 줄에 무엇을 하나씩 더하면 GCN이 되는가”를 따라간다. 더하는 것은 넷이고, 각각이 무엇을 고치는지가 이 문서의 전부다.

## 1. 출발점: 정점마다 같은 MLP { #start-mlp }

정점 $N$개, 입력 특성 $C$, 출력 특성 $F$라 하자.

$$
X\in\mathbb R^{N\times C},
\qquad
W\in\mathbb R^{C\times F},
\qquad
Z=XW.
$$

행 $i$만 쓰면 $z_i=x_iW$다. 정점 수와 관계없이 같은 $W$를 쓰고, 순열 행렬 $P$에 대해 $(PX)W=P(XW)$이므로 정점 순서를 바꾸면 출력 순서만 같이 바뀐다.

하지만 $A$가 식에 없다. 두 정점이 이웃인지 알 수 없다. [01 §4](01_gnn_gentle_guide.md#simplest-gnn)의 “가장 단순한 GNN”이 정확히 이 단계다. [Distill 2021, “The simplest GNN”]

## 2. 연산자를 한 단계씩 만든다 { #build-operator }

### 2.1 이웃 합을 왼쪽에 붙인다

$$
Z=AXW
$$

의 $AX$는 $i$번째 행이 정점 $i$ 이웃들의 특성 합이다. 이제 식이 두 가지 일을 한다.

1. $AX$: **정점 축**에서 이웃 정보를 모은다.
2. $(AX)W$: **특성 축**에서 학습 가능한 변환을 한다.

결합법칙 때문에 $A(XW)=(AX)W$다. “먼저 메시지를 변환하고 합치기”와 “먼저 합치고 변환하기”는 이 선형 경우에 같은 결과다. 다만 결과가 같다는 것이 두 연산이 같은 일을 한다는 뜻은 아니다 — 하나는 세로를, 하나는 가로를 섞는다.

### 2.2 자기 자신을 포함한다 — $\tilde A$ { #self-loop data-toc-label="2.2 자기 자신을 포함한다 — Ã" }

$A$의 대각 원소는 0이므로 $AX$에는 자기 특성이 없다. 갱신할 때 자신의 상태가 통째로 사라지는 것이다. 자기 연결을 더한다.

$$
\tilde A=A+I.
$$

정전(正典, canonical) 그래프 **G4**($V=\{1,2,3,4\}$, $E=\{(1,2),(1,3),(2,4)\}$)에서 $\tilde AX$는 이웃과 자기 자신을 함께 더한 $(6,7,4,6)$이다 — [01 §8](01_gnn_gentle_guide.md#ax-hand-calc)의 손계산과 같은 숫자다.

### 2.3 차수 차이를 조절한다 — $\tilde D$와 $\hat A$ { #degree-normalize data-toc-label="2.3 차수 차이를 조절한다 — D̃와 Â" }

단순 합은 이웃이 많은 정점일수록 값이 커진다. 그래서 **자기 연결을 더한 뒤의** 차수를 다시 센다.

$$
\tilde d_i=\sum_j\tilde A_{ij},
\qquad
\tilde D=\operatorname{diag}(\tilde d_1,\dots,\tilde d_N).
$$

$D$가 아니라 $\tilde D$인 이유는 하나다. 정규화할 대상이 원래 그래프가 아니라 **실제로 전파에 쓰는 그래프** $\tilde A$이기 때문이다.

나누는 방법은 두 갈래다. 받는 쪽 차수로만 나누면 행 평균 $\tilde D^{-1}\tilde A$이고, 양쪽으로 한 번씩 나누면

$$
\hat A=\tilde D^{-1/2}\tilde A\tilde D^{-1/2},
\qquad
\hat A_{ij}=\frac{\tilde A_{ij}}{\sqrt{\tilde d_i\tilde d_j}}
$$

이다. Kipf–Welling이 고른 것은 뒤쪽이다. 대가로 행 합이 1이 아니게 되지만, 행렬이 **대칭**으로 남아 보내는 쪽 차수가 계수에 남고 고유벡터를 **서로 수직으로** 잡을 수 있다. 두 번째 이유가 왜 논문에 중요한지 — 논문이 식 (2)를 적은 **뒤** 두 쪽에 걸쳐 그 식을 스펙트럼 쪽에서 되짚은 이유 — 는 [05 스펙트럼 다리](05_spectral_bridge.md#s6)가 간선 하나의 뺄셈에서부터 만든다. 두 갈래가 각각 무엇을 버리는지는 [02 §5의 세 갈래 비교](02_kipf2017_gcn_guide.md#viz-normalization)가 숫자로 보여 준다. [Kipf & Welling 2017, Eq. (8)]

정전 그래프에서는 $\tilde d=(3,3,2,2)$이므로 $\hat A_{11}=1/3$, $\hat A_{13}=1/\sqrt6$, $\hat A_{33}=1/2$다. 여기까지가 연산자의 전부이고, 학습되는 것은 하나도 없다.

## 3. 비선형 함수를 넣으면 GCN 한 층 { #gcn-one-layer }

$$
H^{(l+1)}=\sigma(\hat A H^{(l)}W^{(l)}).
$$

MLP의 선형층과 활성화 사이에 “정규화된 이웃 집계”가 끼어든 것이다. 앞 절에서 더한 것들을 한 줄씩 되돌려 보면 네 모델이 나온다.

| 모델 | 식 | 각 정점이 보는 정보 |
|---|---|---|
| 독립 MLP | $\sigma(XW)$ | 자기 특성 |
| 단순 이웃 GNN | $\sigma(AXW)$ | 1-hop 이웃 |
| 자기 연결 GNN | $\sigma((A+I)XW)$ | 자기 자신 + 1-hop |
| GCN | $\sigma(\hat AXW)$ | 정규화된 자기 자신 + 1-hop |

이 네 줄이 [01 §8의 계보 스트립](01_gnn_gentle_guide.md#viz-lineage) ①–⑥과 같은 것이다. 그 그림의 여섯 칸을 다시 볼 때 이제 ④ 칸이 어디서 왔는지 알고 볼 수 있다.

마지막의 $\sigma$도 장식이 아니다. 비선형이 없으면 두 층이 $\hat A^2XW$ 하나로 접힌다 — MLP에서 선형층만 쌓으면 한 층이 되는 것과 같은 이야기다.

## 4. 가중치 공유가 중요한 이유 { #weight-sharing }

$W$는 정점마다 따로 존재하지 않는다. 모든 정점과 모든 위치에서 같은 $W$를 사용한다.

- 파라미터 수가 정점 수 $N$에 의존하지 않는다.
- 정점 번호를 바꿔도 같은 지역 규칙을 적용한다.
- 같은 입력/이웃 패턴을 가진 정점은 같은 방식으로 처리된다.

[해설] CNN이 이미지 위치마다 같은 커널을 공유하는 것과 비슷한 목적이 있지만, GCN에는 “위쪽 픽셀”, “왼쪽 픽셀” 같은 고정 위치 역할이 없다. 이웃을 순서 없는 집합으로 집계한다. 공유를 깨면 어떻게 되는지는 계보 스트립 조작부에서 직접 볼 수 있다 — 파라미터가 4개에서 16개로 늘고, 새 정점에 쓸 $W$가 사라진다.

## 5. 순열 등가성을 식으로 확인하기 { #equivariance }

정점 순서를 $P$로 바꾸면

$$
X'=PX,\qquad A'=PAP^\top.
$$

차수와 정규화 행렬도 같은 방식으로 바뀌어 $\hat A'=P\hat AP^\top$가 된다. 그러면

$$
\hat A'X'W
=(P\hat AP^\top)(PX)W
=P\hat AXW.
$$

즉 출력 정점 순서만 $P$만큼 바뀐다. 그래프 수준에서 sum/mean readout을 하면 $P$가 사라져 불변 출력이 된다. [01 §3](01_gnn_gentle_guide.md#permutation)이 말로 한 성질이 여기서 식으로 확인된다.

## 6. 깊이와 수용 영역 { #receptive-field }

한 층은 최대 1-hop, 두 층은 최대 2-hop, $k$층은 최대 $k$-hop 정보를 전달한다.

예를 들어 2층 GCN은

$$
H^{(2)}=\sigma\left(\hat A\,\sigma(\hat AXW^{(0)})W^{(1)}\right)
$$

이다. 정점 $i$는 첫 층에서 이웃 $j$의 정보를 받고, 둘째 층에서 $j$가 첫 층에 받은 이웃의 이웃 정보까지 전달받는다.

여기서 흔히 생기는 오해가 “$k$층이면 $k$-hop 정점이 내 표현에 **균등하게** 들어온다”이다. 그렇지 않다. **수용 집합**(절 제목의 수용 영역과 같은 뜻)은 이진 집합이지만 실제 기여는 $(\hat A^k)_{ij}$라는 **연속량**이고, 경로마다 $\prod 1/\sqrt{\tilde d}$로 감쇠한다.

**G4로는 볼 수 없는 것이 있다.** 정점이 넷이고 지름이 3이라 수용 집합이 1 → 2 → 3 → 4로 늘 뿐이어서 이웃 폭발이 정의상 관찰되지 않고, 병목 간선이 없어 oversquashing도 관찰할 수 없다. 그래서 마지막 프레임만 잎 네 개를 더한 **G4▲**를 쓴다. G4의 네 정점은 좌표·번호·특성 그대로 남는다. 무관한 새 그래프로 바꾸지 않는 이유는, 바꾸는 순간 앞 프레임의 숫자를 이어 나를 수 없기 때문이다.

깊이가 늘면 항상 좋은 것은 아니다.

- 수용 집합이 과제에 필요한 범위보다 커질 수 있다.
- 이웃 수가 빠르게 늘어 계산·메모리가 증가하고, $k$층의 정확한 미니배치가 $k$-hop 이웃 전체를 요구해 어려워진다(G4▲ 프레임의 1 → 2 → 5 → 8). 차수가 큰 그래프에서는 이 증가가 층마다 곱해진다.
- 넓어진 수용 집합의 정보가 병목 간선 하나를 통과해야 할 수 있다. 왼쪽 정점이 몇 개든 G4▲에서 통로의 계수는 $\hat A_{12}=0.20$ 하나다 — 후대 문헌의 **oversquashing**이다.
- 같은 정규화 혼합을 반복하면 정점 표현이 서로 비슷해진다. $\hat A^k$는 $\sqrt{\tilde d}$ 방향으로 수렴하므로, 충분히 깊으면 정점을 구별하는 정보로 차수만 남는다 — [02 §11의 수치](02_kipf2017_gcn_guide.md#viz-oversmoothing).
- 파라미터와 학습 난도가 증가한다.

[원문] Kipf–Welling Appendix B의 데이터에서는 2~3층이 가장 좋았고, 7층보다 깊은 모델은 residual connection 없이 학습하기 어려웠다. [Kipf & Welling 2017, Appendix B]

[후대 용어] 반복 집계로 정점 표현이 비슷해지는 현상을 이후 문헌에서는 흔히 **oversmoothing**, 먼 정보가 좁은 간선에 압축되는 현상을 **oversquashing**이라 부른다. 두 용어 모두 원 논문의 것이 아니고, 원 논문은 Figure 5의 깊이 저하를 어느 한 용어로 단정하지 않았다.

## 7. 구현 관점: 인접 행렬을 정말 만들 필요는 없다 { #edge-list }

수식은 $N\times N$ 행렬로 간결하게 쓰지만 실제 희소 그래프에서는 edge list를 순회하며 다음을 수행할 수 있다.

```text
각 간선 j -> i에 대해:
    message = h[j] / sqrt(deg[i] * deg[j])
    out[i] += message
각 정점 i에 대해:
    out[i] = activation(out[i] @ W)
```

자기 연결도 간선 $(i,i)$를 하나 추가한 것으로 처리할 수 있다. 여기서 `deg`는 자기 연결을 포함한 $\tilde d$다. 이렇게 하면 저장과 집계 비용이 실제 간선 수에 비례한다.

## 8. 30초 체크리스트 { #checklist }

GCN 식을 볼 때 다음 순서로 읽는다.

1. $H$의 행은 정점, 열은 특성이다.
2. 왼쪽의 $\hat A$는 정점 축을 섞는다.
3. 오른쪽의 $W$는 특성 축을 섞는다.
4. 같은 $W$를 모든 정점이 공유한다. 층당 하나이고 정점 수와 무관하다.
5. 층 수가 정보가 이동하는 최대 hop 수를 정한다. 단, **도달하는 것과 영향을 주는 것은 다른 양**이다.
6. 손실이 어느 정점에 계산되는지 따로 확인한다. forward가 도는 정점 집합과 같지 않다.

이 여섯 줄을 들고 다음 문서인 [05 스펙트럼 다리](05_spectral_bridge.md)로 간다. 논문이 식 (2)를 적고 **나서** 두 쪽에 걸쳐 되짚은 유도가 거기서 만들어지고, 그다음이 [02 GCN 논문 해설](02_kipf2017_gcn_guide.md)이다. 손으로 확인하는 문제는 [04](04_exercises.md)에 모여 있다.
