# MLP에서 GCN으로 가는 다리

이 문서는 긴 유도보다 “이미 아는 MLP에 무엇을 하나씩 더하면 GCN이 되는가”에 집중한다.

## 1. 출발점: 정점마다 같은 MLP { #start-mlp }

정점 $N$개, 입력 특성 $C$, 출력 특성 $F$라 하자.

$$
X\in\mathbb R^{N\times C},
\qquad
W\in\mathbb R^{C\times F}.
$$

각 정점에 같은 선형층을 적용하면

$$
Z=XW
$$

이다. 행 $i$만 쓰면 $z_i=x_iW$다.

장점은 두 가지다.

- 정점 수와 관계없이 같은 $W$를 쓴다.
- 정점 순서를 바꾸면 출력 순서만 같이 바뀐다.

순열 행렬 $P$에 대해

$$
(PX)W=P(XW)
$$

이므로 정점 수준 출력은 순열 등가적이다.

하지만 $A$가 식에 없다. 서로 연결된 정점인지 알 수 없다. Distill 글이 말하는 graph-independent한 가장 단순한 GNN/MLP 기준선이 이 단계다. [Distill 2021, “The simplest GNN”]

## 2. 이웃 합을 앞에 붙인다

인접 행렬 $A$를 곱하면

$$
AX
$$

의 $i$번째 행은 정점 $i$의 이웃 특성 합이다. 따라서

$$
Z=AXW
$$

는 다음 두 연산을 한다.

1. $AX$: 정점 축에서 이웃 정보를 모은다.
2. $(AX)W$: 특성 축에서 학습 가능한 변환을 한다.

행렬 곱의 결합법칙 때문에 $A(XW)=(AX)W$다. “먼저 메시지를 변환하고 합치기”와 “먼저 합치고 선형변환하기”가 이 선형 경우에는 같은 결과다.

## 3. 자신의 특성을 포함한다

$A$의 대각 원소가 0이면 $AX$에는 자기 특성이 없다. 자기 연결을 더한다.

$$
\tilde A=A+I.
$$

이제 $\tilde AX$는 이웃과 자기 자신의 특성을 함께 더한다.

## 4. 차수 차이를 조절한다

단순 합은 이웃이 많은 정점일수록 값의 크기가 커지기 쉽다. Kipf–Welling GCN은 자기 연결을 포함한 차수 행렬 $\tilde D$를 만들고

$$
\hat A=\tilde D^{-1/2}\tilde A\tilde D^{-1/2}
$$

를 사용한다. 간선 $(i,j)$의 계수는

$$
\frac1{\sqrt{\tilde d_i\tilde d_j}}
$$

이 된다. [Kipf & Welling 2017, Eq. (8)]

## 5. 비선형 함수를 넣으면 GCN 한 층 { #gcn-one-layer }

$$
H^{(l+1)}=\sigma(\hat A H^{(l)}W^{(l)}).
$$

MLP의 선형층과 활성화 사이에 “정규화된 이웃 집계”가 결합되었다고 보면 된다.

| 모델 | 식 | 각 정점이 보는 정보 |
|---|---|---|
| 독립 MLP | $\sigma(XW)$ | 자기 특성 |
| 단순 이웃 GNN | $\sigma(AXW)$ | 1-hop 이웃 |
| 자기 연결 GNN | $\sigma((A+I)XW)$ | 자기 자신 + 1-hop |
| GCN | $\sigma(\hat AXW)$ | 정규화된 자기 자신 + 1-hop |

## 6. 가중치 공유가 중요한 이유 { #weight-sharing }

$W$는 정점마다 따로 존재하지 않는다. 모든 정점과 모든 위치에서 같은 $W$를 사용한다.

- 파라미터 수가 정점 수 $N$에 의존하지 않는다.
- 정점 번호를 바꿔도 같은 지역 규칙을 적용한다.
- 같은 입력/이웃 패턴을 가진 정점은 같은 방식으로 처리된다.

[해설] CNN이 이미지 위치마다 같은 커널을 공유하는 것과 비슷한 목적이 있지만, GCN에는 “위쪽 픽셀”, “왼쪽 픽셀” 같은 고정 위치 역할이 없다. 이웃을 순서 없는 집합으로 집계한다.

## 7. 순열 등가성을 식으로 확인하기

정점 순서를 $P$로 바꾸면

$$
X'=PX,\qquad A'=PAP^\top.
$$

차수와 정규화 행렬도 같은 방식으로 바뀌어 $\hat A'=P\hat AP^\top$가 된다. 그러면

$$
\hat A'X'W
=(P\hat AP^\top)(PX)W
=P\hat AXW.
$$

즉 출력 정점 순서만 $P$만큼 바뀐다. 그래프 수준에서 sum/mean readout을 하면 $P$가 사라져 불변 출력이 된다.

## 8. 깊이와 수용 영역 { #receptive-field }

한 층은 최대 1-hop, 두 층은 최대 2-hop, $k$층은 최대 $k$-hop 정보를 전달한다.

예를 들어 2층 GCN은

$$
H^{(2)}=\sigma\left(\hat A\,\sigma(\hat AXW^{(0)})W^{(1)}\right)
$$

이다. 정점 $i$는 첫 층에서 이웃 $j$의 정보를 받고, 둘째 층에서 $j$가 첫 층에 받은 이웃의 이웃 정보까지 전달받는다.

</div>

깊이가 늘면 항상 좋은 것은 아니다.

- 수용 영역이 과제에 필요한 범위보다 커질 수 있다.
- 이웃 수가 급격히 늘어 계산·메모리가 증가한다.
- 같은 정규화 혼합을 반복하면 정점 표현이 비슷해질 수 있다.
- 파라미터와 학습 난도가 증가한다.

[원문] Kipf–Welling Appendix B의 데이터에서는 2~3층이 가장 좋았고, 깊은 모델은 residual connection 없이 학습하기 어려웠다. [Kipf & Welling 2017, Appendix B]

[후대 용어] 반복 집계로 정점 표현이 비슷해지는 현상을 이후 문헌에서는 흔히 **oversmoothing**이라 부른다. 원 논문은 Figure 5의 깊이 저하를 이 용어 하나로 단정하지 않았다.

## 9. 반지도 학습에서 라벨 없는 정점의 역할 { #unlabeled-nodes }

2층 GCN의 출력은 전체 정점에 대해 계산된다.

$$
Z=\operatorname{softmax}(\hat A\operatorname{ReLU}(\hat AXW^{(0)})W^{(1)}).
$$

그러나 교차 엔트로피는 라벨이 있는 정점 집합 $\mathcal Y_L$에 대해서만 계산한다. [Kipf & Welling 2017, Eq. (9), Eq. (10)]

라벨 없는 정점도 다음 방식으로 학습에 간접 참여한다.

- 전체 $X$에 자신의 특성을 제공한다.
- $A$에서 메시지 전달 경로를 제공한다.
- 라벨 있는 정점의 표현을 만드는 중간 이웃이 된다.

## 10. transductive와 inductive를 구분하기 { #transductive }

원 논문의 주 실험은 학습할 때 하나의 전체 그래프 구조와 모든 정점 특성을 알고, 그 그래프 안의 라벨 없는 정점을 예측하는 transductive 설정이다.

- **transductive**: 같은 그래프 안의 보지 못한 라벨을 예측
- **inductive**: 학습 때 없던 새 정점이나 새 그래프에도 규칙을 적용

GCN의 공유 가중치라는 아이디어는 inductive 모델 설계에도 쓸 수 있지만, 원 논문의 실험 결과를 새 그래프 일반화의 직접 증거로 읽어서는 안 된다.

## 11. 구현 관점: 인접 행렬을 정말 만들 필요는 없다

수식은 $N\times N$ 행렬로 간결하게 쓰지만 실제 희소 그래프에서는 edge list를 순회하며 다음을 수행할 수 있다.

```text
각 간선 j -> i에 대해:
    message = h[j] / sqrt(deg[i] * deg[j])
    out[i] += message
각 정점 i에 대해:
    out[i] = activation(out[i] @ W)
```

자기 연결도 간선 $(i,i)$를 하나 추가한 것으로 처리할 수 있다. 이렇게 하면 저장과 집계 비용이 실제 간선 수에 비례한다.

## 12. 30초 체크리스트 { #checklist }

GCN 식을 볼 때 다음 순서로 읽는다.

1. $H$의 행은 정점, 열은 특성이다.
2. 왼쪽의 $\hat A$는 정점 축을 섞는다.
3. 오른쪽의 $W$는 특성 축을 섞는다.
4. 같은 $W$를 모든 정점이 공유한다.
5. 층 수가 정보가 이동하는 최대 hop 수를 정한다.
6. 손실이 어느 정점에 계산되는지 따로 확인한다.

## 확인문제

1. $XW$와 $AXW$의 가장 중요한 차이는 무엇인가?
2. 정점별로 서로 다른 $W_i$를 두면 어떤 문제가 생기는가?
3. $PAP^\top$와 $PX$를 함께 써야 하는 이유는 무엇인가?
4. 원 논문의 2층 모델이 2-hop 이하를 보는 이유를 설명하라.
5. transductive 정확도가 높다는 사실만으로 새 그래프에 대한 inductive 성능을 결론 내릴 수 없는 이유는 무엇인가?

## 해답

1. $XW$는 정점을 독립적으로 변환하고, $AXW$는 이웃 특성을 집계한 뒤 변환한다.
2. 파라미터 수가 정점 수에 의존하고, 정점 번호를 바꿀 때 같은 지역 규칙이 유지되지 않으며, 새로운 정점에 적용하기 어렵다.
3. 정점 순서를 바꿀 때 특성 행과 인접 행렬의 두 축을 일관되게 바꿔야 같은 그래프를 나타내기 때문이다.
4. 첫 층에서 1-hop 정보가 각 정점에 들어오고, 둘째 층에서 그 표현을 다시 1-hop 전달하므로 최대 2-hop 정보가 도달한다.
5. transductive 설정은 학습 시 전체 대상 그래프의 구조와 특성을 이미 사용한다. 구조가 다른 새 그래프에 대한 일반화는 별도의 평가가 필요하다.
