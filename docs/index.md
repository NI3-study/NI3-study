# NI3 기초 GNN 스터디

MLP와 역전파를 이해하고 자료구조 과목에서 그래프를 배운 학생을 위한 GNN·GCN 입문 자료입니다.

**GNN 블록은 그래프를 받아 같은 배선의 그래프를 돌려줍니다.** 정점·간선·전역 속성의 값만 갱신되고 연결 구조는 그대로이며, 정점·간선·그래프 수준의 예측은 블록이 아니라 그 뒤에 붙는 head가 만듭니다. 이 한 문장이 자료 전체의 뼈대이고, 자세한 정의는 [01 §2](01_gnn_gentle_guide.md#graph-in-graph-out)에 있습니다.

이 사이트는 두 자료를 중심으로 구성했습니다.

- Sanchez-Lengeling et al., [A Gentle Introduction to Graph Neural Networks](https://distill.pub/2021/gnn-intro/), Distill, 2021
- Thomas N. Kipf and Max Welling, [Semi-Supervised Classification with Graph Convolutional Networks](https://arxiv.org/abs/1609.02907), ICLR 2017

원문을 그대로 번역하기보다, **이미 알고 있는 MLP와 그래프 자료구조에서 GCN으로 건너가는 과정**을 설명합니다.

이 자료는 넓고 깊게 이어질 ML·GNN 커리큘럼의 첫 단계에 해당합니다. 두 원문은 이 단계의 출발 텍스트이지 스터디의 경계가 아니고, "MLP에서 GCN까지"도 이 단계의 통과 구간이지 도착점이 아닙니다.

## 그림을 읽는 하나의 문법 { #visual-lineage }

이 사이트의 그림은 서로 다른 볼거리가 아니라 **한 벌의 기호가 변형되는 계보** 하나입니다. 모든 그림이 같은 **정전(正典, canonical — 사이트 전체가 기준으로 삼는 하나의 표준 예제)** 그래프 G4($V=\{1,2,3,4\}$, $E=\{(1,2),(1,3),(2,4)\}$) 위에서 시작하고, 같은 좌표·같은 번호·같은 행 순서를 씁니다.

G4가 원리적으로 담을 수 없는 현상(차수 격차, 이웃 증가, 병목)에서만 확장 그래프를 씁니다. 그때도 **교체가 아니라 확장**입니다 — G4의 네 정점은 좌표·번호·특성을 그대로 유지한 채 남고, 캡션에 “G4로는 무엇이 관찰 불가능한지”를 한 줄 적습니다.

| 기호 | 형태 | 고정된 뜻 |
|---|---|---|
| 원반 | 테두리 있는 원 | 정점 하나의 정체성 |
| 칸 | 작은 정사각형 | 스칼라 하나 — 특성·계수·고유벡터 성분([05 S5](05_spectral_bridge.md#s5))·기여도의 공통 단위 |
| 현 | 두 원반을 잇는 선 | 간선 하나. 굵기 = 계수, 숫자를 함께 적는다 |
| 자기 고리 | 원반에 걸친 반원 | 정점이 자기 자신에게 주는 계수. 굵기 규칙은 현과 같다 |
| 점선 현 | 두 원반을 잇는 성긴 점선 | 이 프레임에서 값이 흐르지 않는 **실재 간선** — 수용 집합 밖, 또는 제외된 정점에 닿는 간선 |
| 점찍은 현 | 두 원반을 잇는 **가는** 촘촘한 점찍은 선 | 그래프에 **간선이 없는데** 연산자에는 값이 있는 쌍(다항식이 만든 2-hop 계수)([05 S11](05_spectral_bridge.md#s11)) |
| 병목 현 | 두 원반을 잇는 **굵은** 점찍은 선 | 집합과 집합을 잇는 통로가 이 간선 하나뿐이라는 표시 — **실재 간선이다**([03 §6](03_bridge_mlp_to_gcn.md#receptive-field)) |
| 화살 | 방향 있는 짧은 선 | 흐름 하나 — 메시지 **또는** gradient |
| 테 | 폐곡선 | 집합 경계(이웃·수용 집합·라벨 집합), 그리고 **두 격자가 같은 값임을 주장하는 묶음**([05 S8](05_spectral_bridge.md#s8)) |
| 기둥 | 세로 블록 | 학습 파라미터 $W$. 언제나 격자 **오른쪽** |
| 막대 | 0선 기준 가로 막대 | 정점 축 위에 살지 **않는** 양 하나 — 모드별 계수·배수 |
| 축 | 1차원 눈금 | 정점 축 위에 살지 **않는** 양 — 고유값([05 S6](05_spectral_bridge.md#s6)), 층 수, 행 간 거리 |

축 규약에는 예외가 없습니다. **세로 = 정점 축, 가로 = 특성 축, 왼→오 = 층.** 격자의 $i$행은 언제나 원반 $v_i$이고, 그림마다 다시 배우지 않아도 됩니다.

그림은 기본적으로 **정지 프레임**입니다. 재생 버튼도 타이머도 슬라이더도 없습니다. 프레임 스트립이 곧 슬라이더의 모든 위치이고, 애니메이션으로만 전달되는 정보는 없으며 인쇄해도 같습니다. 사이트 전체에 남은 조작은 [$W$ 공유 여부](01_gnn_gentle_guide.md#viz-lineage) 한 종류뿐이고, 그것도 **틀린 상태를 선택할 수 있기 때문에** 남겼습니다. 결과 숫자가 달라지지 않는 선택지는 두지 않았습니다.

## 학습 목표

이 자료를 모두 읽고 나면 다음을 할 수 있어야 합니다.

1. GNN 블록의 입력과 출력이 모두 **같은 배선의 그래프**임을 설명하고, 예측이 블록 밖 head에서 나온다는 것을 구분한다.
2. MLP 한 층과 GNN 한 층의 차이가 **연결 구조를 따르는 순서 불변 집계 하나**임을 설명한다.
3. 메시지 패싱을 자료구조의 이웃 순회와 연결해 설명한다.
4. GCN의 한 층

    $$
    H^{(l+1)}=\sigma\!\left(\tilde D^{-1/2}\tilde A\tilde D^{-1/2}H^{(l)}W^{(l)}\right)
    $$

    에서 각 행렬의 의미와 차원을 설명한다.

5. 작은 그래프에서 자기 연결, 차수 정규화, 한 층 출력을 손으로 계산한다.
6. 원 논문의 결과와 이후 문헌에서 정착한 해석을 구분한다.
